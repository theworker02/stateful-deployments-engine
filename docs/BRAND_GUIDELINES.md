# Brand guidelines (v1.0.0)

## Identity

- **Name:** Stateful Deployments Engine (SDE)
- **Tagline:** Blue/green semantics for workloads that own local state
- **Independence:** Always state “Independent project — not affiliated with Railway.”
- **Do not** use Railway logos, wordmarks, or purple-on-white Railway branding

## Assets

Located in `assets/brand/` and mirrored for Pages in `site/brand/`:

| File | Use |
|------|-----|
| `logo.svg` | Primary lockup (light) |
| `logo-dark.svg` | Dark backgrounds |
| `icon.svg` / `favicon.svg` | App icon / favicon |
| `social-preview.svg` | OG / social card |
